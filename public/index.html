2
粘贴飞书表格链接
电子表格、wiki 链接、多维表格都可以。请确保该表格已共享给本工具的创建者。
3
选择数据表与字段
已识别为「多维表格」。此模式只做 🔵 链接转图片（写入附件字段），不涉及 🟣 提取信息。
转换逻辑：逐条读取记录 → 从「链接字段」抽取图片 URL → 下载并上传到多维表格 → 写回「附件字段」。链接字段含多个 URL 时，每个生成一个独立附件。建议先小范围验证再全量。
3
选择子表，然后扫描
先告诉工具「图片在表里是什么形式」，再点扫描。
② 怎么选？在飞书里点一下那个单元格：直接显示出一张图 → 选第一项；显示的是一串 http… 网址文本 → 选第二项；拿不准就选「两种都有」（稍慢一点，但不会漏）。
